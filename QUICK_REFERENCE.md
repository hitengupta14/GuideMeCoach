# ⚡ Quick Reference Card

## 🚀 Getting Started

```
Go to: /planner
Choose: AI Generation or Custom Planner
Build: Your perfect workout plan
Save: For later use
```

## 🎯 Two Modes

### AI Generation
```
1. Fill form (goal, experience, days, equipment)
2. Click "Generate"
3. Get personalized plan
4. Exercises auto-added to database
5. Click exercises for details
6. Save plan
```

### Custom Planner
```
1. Enter plan name & weeks
2. Select exercises manually
3. Customize sets/reps/rest
4. Add multiple weeks
5. Click exercises for details
6. Save plan
```

## 📍 URLs

```
/planner                     → Main entry
/planner/unified             → Full interface
/planner/unified?mode=ai     → AI mode
/planner/unified?mode=custom → Custom mode

```
